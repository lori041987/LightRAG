  - ## 1. Query orchestration (Summary)
      - Purpose: For mode="hybrid", LightRAG first extracts query keywords (HL/LL) using the configured LLM function, then performs both “local” (entity-centric) and
        “global” (relation-centric) retrieval against the knowledge graph + vector stores, merges the results (round-robin + dedupe), fetches related text chunks,
        optionally reranks/truncates chunks to fit a token budget, builds a final system prompt by injecting the assembled context, and calls the LLM again to
        synthesize the final answer. The script logs the question and the final answer string (non-streaming default) after the query completes.
